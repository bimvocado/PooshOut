# 정화봇 서버 (FastAPI)

출똥! 하수처리장 대탐험의 AI 가이드 '정화봇'을 담당하는 서버.
Unity 클라이언트가 이 서버를 호출하면, 서버가 Upstage Solar로 대사를 만들고
Typecast로 음성을 합성해서 돌려준다.

**API 키는 서버에만 존재한다.** Unity(APK)에는 키가 없으므로
디컴파일로 키가 노출될 위험이 없다.

---

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 서버 본체. 엔드포인트 4개, LLM·TTS 연동, 캐시, 폴백 |
| `generate_lines.py` | 고정 멘트를 wav로 미리 뽑는 도구 (아래 참고) |
| `requirements.txt` | 필요한 파이썬 패키지 |
| `.env.example` | 키 입력용 견본. 복사해서 `.env`로 쓴다 |
| `.gitignore` | `.env`와 생성물이 커밋되지 않도록 막는 목록 |

---

## 실행 방법

### 1. 패키지 설치

```
cd server
pip install -r requirements.txt
```

### 2. API 키 설정

`.env.example`을 복사해 `.env`로 이름을 바꾸고 실제 키를 넣는다.

```
UPSTAGE_API_KEY=up_실제키
TYPECAST_API_KEY=실제키
TYPECAST_VOICE_ID=tc_보이스ID
TYPECAST_MODEL=ssfm-v30
CACHE_ENABLED=1
PUBLIC_BASE_URL=http://localhost:8000
```

Voice ID는 타입캐스트 보이스 목록에서 원하는 목소리를 고른 뒤 복사한다.

> ⚠️ **`.env`는 절대 커밋하지 말 것.** `.gitignore`에 등록돼 있지만,
> 실수로 올라가면 키를 즉시 재발급해야 한다.
> 키가 필요하면 팀 내부 채널로 따로 공유받을 것.

### 3. 서버 실행

```
uvicorn main:app --host 0.0.0.0 --port 8000
```

이 터미널 창을 닫으면 서버도 꺼진다. 실행 중에는 열어둘 것.

### 4. 동작 확인

브라우저에서 `http://localhost:8000` 접속 →
`{"status":"ok","service":"PooshOut 정화봇 서버"}` 가 뜨면 정상.

## 고정 멘트 일괄 생성

게임 중 반복되는 대사는 미리 wav로 뽑아 Unity에 넣는다.
사전 생성이므로 플레이 중에는 API 호출이 없어 지연이 0이다.

```
python generate_lines.py
```

`lines_output/` 폴더에 wav 파일들과 `lines_manifest.json`(파일명 ↔ 대사 ↔ 감정 매핑)이 생성된다.
생성된 파일은 Unity의 `Assets/Audio/Poosh/`로 복사해서 쓴다.

**대사를 고치려면** `generate_lines.py` 안의 `LINE_SETS` / `NICKNAME_LINE_SETS`만 수정하고
스크립트를 다시 돌리면 된다.

### 생성되는 것

- **고정 멘트** — 지도 교육 멘트, 조작 설명, 스테이지별 칭찬/격려 등
- **닉네임 대사** — 닉네임 12종 × 3개 대사 (첫 인사, 변신, 작별)

닉네임 대사까지 미리 뽑는 이유: 실시간 TTS로 처리하면 매번 몇 초씩 대기가 생기고,
구독이 끝나면 아예 동작하지 않는다. 미리 뽑아두면 지연이 없고 구독 해지 후에도 계속 쓸 수 있다.

호격조사(야/아)가 받침에 따라 달라지는 문제를 피하려고
모든 대사를 `{닉네임}, ~` 형태(쉼표)로 작성했다.

### 실시간으로 남는 것

**마무리 피드백 하나뿐이다.** 아이마다 플레이 로그가 달라 미리 만들 수 없기 때문에,
이 부분만 게임 종료 시 LLM + TTS를 실시간 호출한다.

## Unity 쪽 설정

`Assets/Scripts/Core/ServerConfig.cs`의 `SERVER_URL`이 서버 주소를 가리켜야 한다.

- **에디터 테스트**: `http://localhost:8000` (기본값)
- **Quest 실기기**: 서버를 돌리는 PC의 IP로 변경
  예) `http://192.168.0.10:8000`
  (Quest와 PC가 같은 Wi-Fi에 있어야 함. PC IP는 `ipconfig`로 확인)

실기기에서 음성을 받으려면 `.env`의 `PUBLIC_BASE_URL`도 같은 IP로 바꿔야 한다.
`localhost`로 두면 Quest가 자기 자신을 찾게 되어 음성이 재생되지 않는다.

| 메서드 | 경로 | 용도 |
|---|---|---|
| POST | `/chat` | 범용 대사 생성 (LLMConnector가 사용) |
| POST | `/commentary` | 스테이지 중계 해설 |

| POST | `/leaderboard` | 기록 저장 (닉네임 중복 시 번호 자동 부여) |

| DELETE | `/leaderboard/all` | 전체 초기화 (관리용, 클라이언트 미사용) |
| DELETE | `/leaderboard/{name}` | 특정 닉네임 삭제 (관리용, 클라이언트 미사용) |
| GET | `/` | 헬스체크 |

요청/응답 필드 상세는 `docs/server-api-spec.md` 참고.

## 설계 메모

**캐시** — 아이가 바뀌어도 "스테이지 진입/클리어" 상황은 반복된다.
첫 요청에서 생성한 결과를 재사용하므로 두 번째부터는 대기 시간이 없다.
마무리 피드백은 플레이 로그가 매번 달라 자연히 캐시에 걸리지 않으므로,
"AI가 매번 새로 만든다"는 성격은 그대로 유지된다.
개발 중 매번 새 대사를 보고 싶으면 `.env`에서 `CACHE_ENABLED=0`.

**3단계 폴백** — 정화봇이 조용해지는 최악의 상황을 막기 위해:
1. LLM 실패/타임아웃 → 미리 준비된 고정 멘트
2. TTS 실패 → 음성 없이 텍스트만 (`audioUrl: null`)
3. 서버 자체가 죽음 → Unity의 오프라인 폴백 대사

**문장 길이** — LLM에게 "짧게"를 부탁만 하면 가끔 안 지킨다.
`clamp_sentences()`가 서버에서 3문장으로 자르고,
문장부호 없이 끝난 미완성 조각은 버린다(TTS가 토막을 읽는 사고 방지).

**이모지 정제** — TTS가 이모지를 "눈웃음"처럼 이름으로 읽어버리므로,
`sanitize_for_tts()`가 음성용 텍스트에서만 제거한다. 화면 표시용 원문은 그대로 둔다.

## 공모전 제출 관련 (중요)

현재 **유료 플랜을 결제하여 사용 중**이므로, 게임 내 타입캐스트 음성의 출처 표기를 생략할 수 있다. 

타입캐스트 고객센터 공식 문의 결과(2026.08)에 따른 라이선스 적용 내용은 다음과 같다.

1. **상업적 이용 및 출처 표기 면제**
   수상 상금이 있는 공모전 출품은 물론, 수상 이후 홍보/마케팅(홍보 영상, 보도자료 등 상업적 활용)으로 이용하는 경우에도 유료 플랜 생성물은 출처 표기 없이 자유롭게 사용 가능하다.
2. **구독 해지 후 영구 사용 가능**
   유료 플랜 구독 기간 내에 생성 및 다운로드까지 완료한 음성 파일은, 향후 구독을 해지하더라도 게임에 포함된 상태로 영구적으로 계속 사용할 수 있다.
3. **주의사항**
   구독 종료 후에는 파일 추가 생성 및 재다운로드가 불가능하다. 따라서 제출 전 필요한 모든 대사는 반드시 구독 기간 내에 `generate_lines.py`를 실행하여 100% 생성 및 다운로드를 완료해야 한다.
